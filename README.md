# 📦 FedEx Supply Chain Delivery Analysis

## 📌 Project Description

This project involves performing Exploratory Data Analysis (EDA) on FedEx Supply Chain delivery data to understand shipment trends, delivery costs, vendor performance, and country-wise distribution. The goal is to extract meaningful insights that can help improve logistics operations and supply chain decision-making.

---

## 🎯 Project Objectives

- Explore and understand supply chain delivery data.

- Identify trends in shipment methods and delivery costs.

- Evaluate vendor performance based on transaction value.

- Analyze country-wise shipment distribution.

- Generate business insights through data visualization.

---

## 🛠️ Technologies Used

- Python

- Pandas

- NumPy

- Matplotlib

- Seaborn

- Google Colab

---

## 📊 Analysis Workflow

### Data Collection & Understanding

- Loaded the dataset using Pandas.

- Examined dataset structure, data types, and summary statistics.

### Data Cleaning

- Checked for missing values.

- Removed duplicate records.

- Validated data quality before analysis.

### Exploratory Data Analysis

- Analyzed shipment mode distribution.

- Evaluated average delivery cost across shipment methods.

- Compared vendor performance based on line item value.

- Performed country-level shipment analysis.

- Explored transaction value distribution and outliers.

### Data Visualization

Created visualizations using Matplotlib and Seaborn, including:

- Bar Charts

- Pie Charts

- Histograms

- Boxplots

---

## 📈 Key Findings

- Air shipments recorded higher average costs compared to other transportation methods.

- Vendor performance varied considerably, indicating differences in delivery value and operational scale.

- Shipment mode had a significant impact on overall delivery expenses.

- Certain countries contributed a larger share of shipment activity and delivery costs.

- A majority of deliveries were concentrated within a limited number of shipment methods.

---

## 🚀 Business Insights

- Optimizing shipment mode selection can help reduce transportation costs.

- Monitoring vendor performance can support better supplier management.

- Country-level shipment analysis can assist in identifying high-demand regions.

- Understanding cost distribution helps uncover opportunities for operational improvements.
